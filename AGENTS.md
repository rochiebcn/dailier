## Architecture (Current, Discoverable)

- Auto-configured modules are dependency-driven from `pom.xml`:
  - Web MVC + Thymeleaf (`spring-boot-starter-webmvc`, `spring-boot-starter-thymeleaf`)
  - Data/JPA + Liquibase (`spring-boot-starter-data-jpa`, `spring-boot-starter-liquibase`)
  - REST client + OpenAPI (`spring-boot-starter-restclient`, `springdoc-openapi-starter-webmvc-ui`)
- Data migration folder exists but is empty: `src/main/resources/db/changelog`.
- UI/static folders exist but are empty: `src/main/resources/templates`, `src/main/resources/static`.

## Critical Workflows
- Use Maven Wrapper, not system Maven:
  - Windows: `./mvnw.cmd spring-boot:run`
  - Cross-platform: `./mvnw test`
- `compose.yaml` currently defines no services (`services: {}`); `HELP.md` warns app startup support is incomplete until at least one service is added.
- Current test status: `./mvnw.cmd test -q` fails because no datasource is configured (Liquibase/JPA auto-config starts and cannot determine a JDBC driver URL).
- Minimal app config is only app name in `src/main/resources/application.yaml`; no profiles or datasource properties are defined yet.

## Conventions To Follow In This Repo
- Keep new Java classes under `com.personal.dailier` unless package boundaries are intentionally introduced.
- Prefer feature-aligned packages once code grows (for example `.../daily/...`, `.../common/...`) rather than dumping classes at root package level.
- If adding JPA entities/repositories, add matching Liquibase changelogs under `src/main/resources/db/changelog` in the same change.
- If adding MVC views, pair controller route + Thymeleaf template under `src/main/resources/templates`.
- Lombok is available and configured as annotation processor in `pom.xml`; generated bytecode excludes Lombok from final artifact via Spring Boot plugin config.

## Integration Points And Expectations
- Database runtime dependency is `org.xerial:sqlite-jdbc`; datasource wiring is not implemented yet.
- Docker Compose integration is enabled by dependency (`spring-boot-docker-compose`) but currently has no declared containers.
- OpenAPI UI dependency is present; once controllers exist, docs should be reachable through springdoc defaults.
- DevTools is runtime-optional; expect restart behavior only in local dev run, not tests.

## Agent Operating Notes
- Treat this repo as "scaffold-first": verify assumptions against `pom.xml` and `HELP.md` before implementing features.
- When creating first real feature, include all four pieces together: controller/service/data model + migration + test + config needed to boot.
- Do not assume existing persistence schema, external services, or profiles; define them explicitly in code/config as part of your change.
